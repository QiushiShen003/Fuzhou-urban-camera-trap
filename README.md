# Fuzhou-urban-camera-trap
Raw data and code of 2026-08 research paper "In the city’s backyard: a case study of mammal and bird fauna sustained by urban and suburban forests in Fuzhou City, southeastern China"

Regarding data:
"Data_github" contains camera trapping records;
"Fuzhou_Camera_info_github" contains camera traps' study plot ascription, elevation, working history (Install stands for the start of a working period, and Check stands for the end), and monitoring duration.
"species_inventory_github" is the full inventory of the species captured, contains information of each species such as RAI and conservation status.

Regarding code:
"FZ_primary" contains the major code contents, and the other two files each contain codes for rarefraction curve and ANOSIM analysis.
